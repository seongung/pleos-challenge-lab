# Pleos Journal — demo assets

All families, events, stories and past journals are fictional sample content. Photos were generated with OpenAI image generation for this demo; no real family records were imported.

Speech uses ElevenLabs eleven_v3, Sarah voice, Korean. The user approved the nine-second preview on 2026-11-15. Dictation is 12.72 seconds; the family remark is 3.52 seconds. These are prerecorded demo clips; transcription is simulated locally. No API credential is bundled.

The original instrumental soundtrack was generated through vidIQ music generation on 2026-11-15. Track ID: b2ec054b-2411-4b95-bb8e-5241b1f708fe. Job ID: job_268b7f6b-ae14-4ae8-8686-9e7fc26a4396. Duration: 147.9575 seconds. Prompt: warm acoustic pop for a family album app demonstration, relaxed 92 BPM, fingerpicked guitar, sparse felt piano, warm bass and brushed percussion; instrumental with a steady quiet arrangement.

The final video records the actual Android demo. Background music is mixed after capture. The app is an offline prototype; generated journal text, speech recognition, sharing and cloud synchronization are not production services.

The v4.1 visual design was created by a separate Claude Code designer in Rex, informed by Mobbin iOS references from Journal, 5 Minute Journal, How We Feel, stoic. and corner. A separate Claude Code implementation agent builds the functional app from that design contract. Mobbin reference screenshots are not bundled in the APK.

# Pleos Journal (가제) 기능 유즈케이스

- 작성일: 2026-11-11
- 범위: Pleos SDK 기반 기능만 포함 (외부 API 사용 UC 제외)
- 데모 핵심(P1): UC-01, UC-03, UC-06, UC-07b, UC-11, UC-12

## 상태 표기

| 표기 | 의미 |
|---|---|
| 가용 | Vehicle SDK로 조회 가능 |
| 더미 | 준비 중 SDK, 데모에서는 더미 신호로 시연 |
| 확인 | 사용 가능 여부 미확인 |
| 앱 내부 | SDK 없이 앱 자체 로직으로 구현 |

## 유즈케이스 목록

| ID | 유즈케이스 | 트리거 | 앱 동작 | 신호/API (상태) | 우선 |
|---|---|---|---|---|---|
| UC-01 | 트립 자동 시작/종료 | 운전석 착석 + 트립 거리 증가 / 거리 변화 없음 + 도어 열림 | 트립 엔트리 생성, 시각, 출발/도착지 기록 | Seat, Door, Odometer (가용), 위치 (더미) | P1 |

| UC-03 | 구간 태그 생성 | 신호 상태 변화 | 창문 열림, 비(와이퍼), 야간(전조등), 휴식(뒷좌석 등받이 젖힘) 구간 표시 | Window, Wiper, Light, Seat, HVAC (가용) | P1 |
| UC-04 | 재생 음악 기록 | 곡 변경 | 곡과 시각을 트립에 연결 | 앱 내 플레이어 또는 MediaSession (확인) | P2 |
| UC-06 | 음성 북마크 | 음성 명령 ("지금 기억해줘") | 발화 저장 + 그 시점 위치, 곡, 태그로 핀 생성, 확인음만 출력 (화면 조작 없음) | STT, TTS (더미) | P1 |
| UC-07b | 음성 회고 | 트립 종료 감지 | 긴 트립은 질문 1~2개 제시 후 음성 답변을 텍스트로 저장, 짧은 반복 트립은 알림 없음 | STT, TTS (더미) | P1 |
| UC-08 | 지연 기록 | 미기록 트립 존재 | 일정 기간 내 리마인드, 나중에 추가 | 앱 내부 | P3 |
| UC-09 | 정차 중 편집 | 정차 상태 (충전 대기 등) | 텍스트, 메모 입력 UI는 정차 시에만 개방 | CarUxRestrictions (확인) | P2 |
| UC-10 | 트립 수정 | 사용자 요청 | 트립 병합, 분할, 삭제, 순간 숨기기 (UC-01 오판 보완) | 앱 내부 | P2 |
| UC-11 | 저널 타임라인 | 앱 실행 | 날짜별 카드, 지도 위 경로와 핀, 구간 태그 아이콘 | 저장 데이터 | P1 |
| UC-12 | 자동 하이라이트 | 트립 종료 | 규칙 기반 "오늘의 장면" 제안 (예: 창문 열림 + 같은 곡, 휴식 구간, 비 오는 구간) | 저장 데이터 | P1 |
| UC-13 | 재방문 회상 | 과거 기록 장소 근처 진입 | "1년 전 이곳" 알림 (정차 시 화면, 주행 중엔 음성) | 위치, TTS (더미) | P2 |
| UC-14 | 기간 리캡 | 주말, 연말, 차량 매각 시 | 거리, 함께한 사람, 많이 간 곳, 대표 장면 요약 | 저장 데이터 | P2 |
| UC-15 | 조건 검색 | 사용자 검색 | "비 온 날", "엄마랑 간 곳" 등 태그 기반 검색 | 저장 데이터 | P3 |
| UC-17 | 공유 카드 내보내기 | 사용자 요청 | 하루 또는 장면을 이미지로 공유 | 앱 내부 | P3 |
| UC-18 | 프라이버시 설정 | 최초 실행, 설정 | 항목별 기록 on/off, 동승자 녹음 동의, 기록 일시정지 | 앱 내부 | P3 (기획서 필수 언급) |

## 삭제된 유즈케이스 (외부 API 의존)

| ID | 유즈케이스 | 삭제 사유 | 비고 |
|---|---|---|---|
| UC-05 | 장소, 날씨 보강 | 외부 날씨 API 필요 | 비, 야간은 UC-03이 차량 신호로 일부 대체 |
| UC-07 | 회고 인터뷰 (LLM 요약) | 외부 LLM 필요 | UC-07b로 대체 (STT 텍스트 그대로 저장) |
| UC-16 | 폰 동기화, 사진 매칭 | 자체 클라우드 필요 | Pleos 공식 폰 연동 확인 시 로드맵으로 재추가 |

## 메모

- UC-01: 시동, 기어, 속도 신호가 SDK에 없어 종료 판정을 조합 로직으로 구현해야 함. 오판 시 트립 분할/병합 발생, UC-10으로 보완.
- 주행 중 상호작용은 음성(UC-06)과 음성 알림(UC-13)으로 한정, 화면 입력은 정차 시에만 개방(UC-09). 주의분산 심사 가이드 준수.
- 기획서에 실동작(가용) 부분과 더미 시연 부분을 구분해 명시.
- 확인 필요: MediaSession 접근 권한, CarUxRestrictions 연동, Pleos 폰 연동 기능 존재 여부.

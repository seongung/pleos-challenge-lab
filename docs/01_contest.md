## 참가 자격

- 대학(원)생, 일반인, 스타트업. 개인 또는 최대 5인 팀.
- 시상 부문: 대학생 / 일반(스타트업 포함).

## 심사 기준 (1차 서류, 공개된 4항목)

1. 차량특화성
2. 창의성
3. 기술 활용성
4. 사업성

- 상세 PT 심사 기준은 추후 안내(외부 피드백 기준, 확인 필요).
- 최종 순위는 2차 PT에서 제출, 시연한 결과물 기준으로 확정.

## 제출물

- 기획서: 필수.
- 개발 산출물(시연 영상, GitHub 저장소, APK): 선택이나 **단계별 가산점**.
- 1차 영상에는 목업 가능(외부 피드백 해석, 확인 필요).
- 2차 PT 대상 팀은 PT 전까지 **실제 동작 가능한 앱** 완성 필수.
- 비공개 GitHub 저장소 제출 가능. 심사용 계정을 Collaborator로 초대해야 함.

## 주제 예시

인카 엔터테인먼트, 모빌리티 라이프 케어, 안전 운전, 패밀리 및 동승자 케어.
공식 안내상 이는 예시이며 별도 지원 분야 구분은 없음(외부 피드백 확인 내용).

## 개발 환경 요구사항

- Android API 28 이상
- Gradle 8.0 이상
- Java 또는 Kotlin

## 배경

- 2026-08 사내 해커톤 "24H 코드 레이스"에 이어 외부로 확장한 공모전.
- 공모전 측이 발굴 아이디어의 실제 서비스 출시 가능성을 검토한다고 언급.

## 규정상 주의

- "가용 SDK만 사용하라"는 명시 조항은 확인 범위에서 없음.
- 외부 API 금지 조항도 확인 범위에서 없음. 외부 API 미사용은 **팀의 자체 결정**(기술 활용성과 차량특화성 강화 목적).
- Pleos App Market 심사 기준: Vehicle SDK 퍼미션은 사전 협의, 승인된 경우만 선언 가능. 미승인 퍼미션 선언 시 마켓 심사 불통과. (공모전 심사와는 별개)

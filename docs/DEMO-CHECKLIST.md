# Demo acceptance checklist

Status: not started. Choose the app before implementing these.

- [ ] One complete user scenario works in a clean emulator installation.
- [ ] Parked setup is clear and brief.
- [ ] A real SDK input or navigation request drives the useful outcome.
- [ ] CarUxRestrictions change the permitted UI/behavior correctly.
- [ ] Missing permission, unsupported capability, disconnection, and network loss have clear fallbacks.
- [ ] Audio respects navigation/audio focus if the app uses it.
- [ ] Simulated data is labeled; no unsupported claims about live parking, accessibility, charging ETA, or driver detection.
- [ ] A release APK installs and runs using the README steps.
- [ ] Video, repository, and APK links work for the reviewer.
- [ ] README records exact test versions, settings, and APK path.

Proposed video length: 60–90 seconds (team recommendation; not an official limit).

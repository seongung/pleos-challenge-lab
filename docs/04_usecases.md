# 04. 유즈케이스 v2

- 작성일: 2026-11-13
- 변경 근거: v1(2026-11-11, `reference/usecases_v1_2026-11-11.md`)에 외부 AI 검토 피드백(`reference/review_feedback_2026-11-13.md`) 반영
- 범위: Pleos SDK와 앱 내부 로직만 사용 (외부 API 사용 UC 제외)

## 핵심 흐름 (데모의 한 장면)

```
차량 이벤트 수집 → 근거가 보이는 장면 후보 → (UX 제한 해제 상태) 음성 한마디 기록 → 저장, 다시 보기 → 잘못된 단서 수정
   UC-01, 03          UC-12                      UC-09, 07b                  UC-11           UC-10
```

## v1 대비 주요 변경

| 변경 | 이유 |
|---|---|
| UC-01과 UC-10을 "자동 초안 + 사용자 보정"으로 묶어 둘 다 P1 | 시동, 기어, 속도 신호가 없어 트립 오판은 피할 수 없음 |
| UC-03 단서는 단정 금지, "관측 사실 → 제안 → 확인" | 와셔액, 터널, 오토라이트 등 오인식 가능 |
| UC-09 P2 → P1 | 회고 입력과 편집은 플랫폼 UX 제한 상태로만 개방, 모르면 닫음 |
| UC-11 지도 의존 제거, 시간축 타임라인 중심 | 외부 API 없이 지도 표시 가능 여부 미확인 |
| UC-18 P3 → P1(최소 화면) | 프라이버시는 PT 질문 대상 |
| UC-06 P1 → P2(조건부) | 음성 호출 경로, 오디오 포커스, 주행 중 허용 경로 미확인 |
| UC-02 자동 확정 금지 | 착석만으로 신원을 알 수 없음, 제안 후 확인 |

## 단서 규칙표 (UC-03, UC-12)

원칙: 앱은 **관측 사실**만 저장한다. 해석은 **질문**으로 제안하고, 사용자가 확인한 것만 태그가 된다.

| 관측 신호 | 저장하는 사실 | 제안 질문 예 | 알려진 오판 원인 |
|---|---|---|---|
| 와이퍼 작동이 일정 시간 지속 | "와이퍼 작동 14:02~14:40" | "이때 비가 왔나요?" | 와셔액 분사, 오토와이퍼 민감도 |
| 하향등 점등 지속 | "전조등 켜짐 18:10~19:30" | "어두워진 뒤 달린 길이었나요?" | 터널, 오토라이트, 주간 수동 점등 |
| 창문 열림 지속 | "창문 열림 15:20~15:45 (운전석, 조수석)" | "창문 열고 달린 구간이 있었어요. 어떤 길이었나요?" | 짧은 환기, 톨게이트 |
| 뒷좌석 착석 + 등받이 젖힘 | "뒷좌석 등받이 젖힘 16:00~17:10" | "뒷좌석에서 쉬던 시간이었나요?" | 짐 적재, 착석 센서 오판 |
| 도어 열림 + 거리 변화 없음 | "정차, 도어 열림 12:30~13:40" | "여기서 무엇을 했나요?" | 동승자만 하차, 짐 꺼냄 |
| 실내온도와 설정온도 | "실내 24도, 설정 22도" | (질문 없이 메타데이터로만 표시) | 센서 위치 차이 |

- 지속 시간 임계값은 시나리오 재생으로 튜닝하고 코드 상수로 관리.
- 사용자가 "아니요"라고 하면 해당 단서는 숨기되 원시 관측은 보존(삭제 요청 시 삭제).

# Release APK

The separate interactive showcase APK is available in [Pleos Journal v4.1](https://github.com/seongung/pleos-challenge-lab/releases/tag/pleos-journal-v4.1). It is a debug-signed offline prototype, not the release build of the root Pleos SDK application. See [showcase instructions](../showcase/pleos-journal-v4.1/README.md).

When ready, upload the executable release build as `팀명_앱이름_release.apk` in this directory. If it exceeds GitHub upload limits, publish a GitHub Release and record its URL here, in the root README, and in the application.

Validate installation and the full demo flow on a clean Pleos emulator before submission.

Official guidance: https://appdevchallenge.auto-hmg.io/guide/submission#github
